# Astrosifre

Bir astroloji sitesi yapmak istiyorum. Bireysel danışmanlık vermek istemiyorum. İçinde diğer sitelerde olmayan hesaplamalar olcak yükseleni bul ya da Horary (saat/soru astrolojisi) gibi kayıt olmadan bazı özellikleri erişecekler. Üyelik zorunlu değil; bazı detaylı raporlar için tek seferlik ödeme sistemi olacak, ancak birden çok kişinin haritasını kaydedip bakabilmeleri için opsiyonel hesap oluşturabilecekler. Rapor tarafında da ücretsiz bazı raporlar e-posta ile talep edilebilecek fakat hemen teslim edilmeyip sıraya alınarak 48 saat veya bir hafta içinde teslim edilecek; ücretli raporlar ise öncelikli/anlık teslim edilecek.
